# X-Console knob colours on the metal pages. Edit with X-Console Theme Editor.exe (or here), then build the plugin.
# [plugin tag] blocks; ALL / key = every page with that knob; PAGE / key = one page (wins over ALL).
# A value is one of the plugin's own cap styles (the editor lists them), a shaped cap in any colour (hexx-silver-red:#6aa8e8)
# (a pointer cap takes #skirt/#top, either may be empty: pointer-red:/#c0c0c0), or #body/#pointer (#body alone: Molten's chicken-heads).
# A knob that isn't listed keeps the page's own colour.
